# Sistem Alter Baju

## Jalankan secara tempatan (untuk uji di komputer)
```
node server.js
```
Buka http://localhost:3000

## Deploy ke Render.com (percuma, dapat pautan tetap)
1. Daftar akaun di render.com
2. New > Web Service > sambungkan/upload folder ini
3. Build Command: (kosongkan)
4. Start Command: node server.js
5. Deploy — dapat pautan tetap seperti https://nama-anda.onrender.com
6. Letak pautan ini dalam WhatsApp Business anda
